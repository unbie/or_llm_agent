## 💡 论文撰写建议

### 1. 图表编号规则
- 按章节编号：第6章的第1个图表为"图6.1"
- 表格和图分别编号：表6.1, 表6.2, ...; 图6.1, 图6.2, ...

### 2. 图表位置
- 图表应放在首次引用之后的位置
- 避免跨页断开
- 大图可以单独占一页

### 3. 图表说明（Caption）要素
- **图题**：放在图的下方
- **表题**：放在表的上方
- 包含：图表编号、简短标题、必要的说明

示例：
```
图6.1 算法稳定性箱线图
（箱体表示四分位数范围，须线表示极值，中线表示中位数）
```

### 4. 正文引用规范
- 首次出现：完整引用"如图6.1所示"
- 再次引用：可简化为"见图6.1"
- 多个图表：图6.1-6.3，或图6.1和图6.2

### 5. 数据精度
- 成本：保留2位小数或整数（如 69,972.19元）
- 百分比：保留1-2位小数（如 5.15%）
- 时间：保留整数即可（如 131秒）

## ⚠️ 特别注意

### Gap to BKS 的说明
由于本文的成本模型包含了生鲜特性（货损、制冷等），而BKS只优化距离，两者**不具有直接可比性**。

**建议处理方式**：
1. **在论文中淡化Gap指标**，不要过分强调
2. **重点放在算法自身性能上**：稳定性、计算效率
3. **与BKS对比时**，只对比路径结构（车辆数），不对比成本

**论文中的表述示例**：
> "需要说明的是，Solomon Benchmark的BKS仅优化行驶距离，而本文优化的是包含生鲜特性的综合成本，两者的优化目标不同，因此无法直接对比总成本。但从路径结构来看，本文采用了更多车辆（表6.6），这是为了缩短配送时间以降低货损成本，符合生鲜配送的实际需求。"

## 📝 Word文档插入图片步骤

1. 在Word中点击"插入" → "图片" → "此设备"
2. 选择 `experiments_batch/figures/` 下的PNG文件
3. 右键图片 → "插入标题" → 选择"图"
4. 输入标题文字，如"算法稳定性箱线图"
5. 设置图片大小（建议宽度12-15cm）
6. 在正文中引用：插入 → 交叉引用 → 选择对应图编号

---

## 📊 Excel处理CSV表格

1. 打开 `experiments_batch/tables/` 下的CSV文件
2. 调整格式：
   - 成本列：添加千位分隔符，保留2位小数
   - 百分比列：设置为百分比格式
3. 美化表格：
   - 添加表头底纹（浅灰色）
   - 设置边框
   - 居中对齐
4. 复制到Word：选中表格 → Ctrl+C → 在Word中Ctrl+V
5. 在Word中调整：表格工具 → 设计 → 选择样式
