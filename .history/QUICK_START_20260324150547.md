# 🚀 快速开始指南

## ⚡ 5分钟快速部署

### 第一步：准备登录参数

在开始前，你需要从校园网登录页面获取认证参数：

1. **打开登录页面**：http://172.18.3.3

2. **获取参数**（推荐用F12开发者工具）：
   - 按 `F12` 打开浏览器开发者工具
   - 切换到 **Network** 标签
   - 输入用户名、密码，点击登录
   - 找到 POST 请求，查看 **Form Data** 中的参数

3. **记录参数**：
   - `username`: 你的学号（如：1810301001）
   - `password`: 你的密码
   - `ac_id`: 认证ID（通常为 1，部分校园网可能不同）
   - `POST URL`: 登录接口（通常为 http://172.18.3.3）

### 第二步：自动部署

**最简单的方法**（推荐）：

```bash
# 1. 下载部署脚本（或从已有目录运行）
cd /path/to/scripts

# 2. 赋予执行权限
chmod +x install_campus_login.sh

# 3. 运行部署脚本（需要sudo）
sudo ./install_campus_login.sh
```

部署脚本会：
- ✅ 自动检查和安装依赖
- ✅ 复制脚本到系统目录
- ✅ 引导配置认证参数
- ✅ 测试登录功能
- ✅ 配置crontab/systemd自启
- ✅ 设置日志轮转

### 第三步：验证安装

```bash
# 查看安装的脚本
ls -la /usr/local/bin/campus_network_login*

# 查看配置文件
sudo cat /etc/campus_login.conf

# 查看日志
tail -f /var/log/campus_login.log
```

## 📚 如果你想手动配置

如果不想使用自动安装脚本，可以手动操作：

### 步骤1：复制脚本文件

```bash
# 复制基础脚本
sudo cp campus_network_login.sh /usr/local/bin/
sudo chmod +x /usr/local/bin/campus_network_login.sh

# 复制高级脚本（可选）
sudo cp campus_network_login_advanced.sh /usr/local/bin/
sudo chmod +x /usr/local/bin/campus_network_login_advanced.sh
```

### 步骤2：创建配置文件

```bash
# 使用高级脚本生成配置模板
sudo /usr/local/bin/campus_network_login_advanced.sh --generate-config

# 或手动编辑
sudo nano /etc/campus_login.conf
```

在配置文件中填入：
```bash
USERNAME="your_student_id"      # 你的学号
PASSWORD="your_password"        # 你的密码
AC_ID="1"                       # 认证ID（根据实际修改）
LOGIN_URL="http://172.18.3.3"   # 登录URL
```

### 步骤3：测试脚本

```bash
# 执行一次登录
/usr/local/bin/campus_network_login.sh

# 查看日志
tail -f /var/log/campus_login.log
```

### 步骤4：配置自启动

**方案A：使用crontab（简单）**

```bash
# 编辑crontab
sudo crontab -e

# 添加以下行（每5分钟检查一次）
*/5 * * * * /usr/local/bin/campus_network_login.sh

# 验证
sudo crontab -l
```

**方案B：使用systemd（推荐）**

```bash
# 创建服务文件
sudo nano /etc/systemd/system/campus-login.service
```

内容：
```ini
[Unit]
Description=Campus Network Auto-Login Service
After=network.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/campus_network_login.sh
StandardOutput=journal
StandardError=journal
```

```bash
# 创建定时器
sudo nano /etc/systemd/system/campus-login.timer
```

内容：
```ini
[Unit]
Description=Campus Network Auto-Login Timer
Requires=campus-login.service

[Timer]
OnBootSec=60s
OnUnitActiveSec=5min
Persistent=true

[Install]
WantedBy=timers.target
```

```bash
# 启用并启动
sudo systemctl daemon-reload
sudo systemctl enable campus-login.timer
sudo systemctl start campus-login.timer

# 检查状态
sudo systemctl status campus-login.timer
```

## 🔧 配置参数详解

### 基础参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `USERNAME` | 学号/用户名 | `1810301001` |
| `PASSWORD` | 密码 | `mypassword123` |
| `AC_ID` | 认证ID | `1` |
| `LOGIN_URL` | 登录页面地址 | `http://172.18.3.3` |

### 高级参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `TEST_HOST` | 测试网络连通性的目标 | `172.18.3.3` |
| `LOG_FILE` | 日志文件路径 | `/var/log/campus_login.log` |
| `RETRY_INTERVAL` | 失败后的重试等待时间（秒） | `10` |
| `MAX_RETRIES` | 最大重试次数 | `3` |

### 告警参数

| 参数 | 说明 |
|------|------|
| `ENABLE_EMAIL_ALERT` | 是否启用邮件告警（true/false） |
| `EMAIL_TO` | 告警邮箱地址 |

## ⚠️ 常见问题和解决方案

### Q1: 脚本说"找不到配置文件"

**原因**：未创建配置文件
**解决**：
```bash
sudo /usr/local/bin/campus_network_login_advanced.sh --generate-config
```

### Q2: 登录总是失败

**排查步骤**：

1. **验证网络连通**
```bash
ping -c 1 172.18.3.3
curl -v http://172.18.3.3
```

2. **测试登录命令**
```bash
# 根据实际参数修改
curl -X POST \
  -d "username=your_id&password=your_pwd&ac_id=1" \
  http://172.18.3.3
```

3. **检查参数**
   - 用户名/学号是否正确？
   - 密码是否包含特殊字符？
   - ac_id 是否正确？

4. **查看完整错误日志**
```bash
tail -50 /var/log/campus_login.log
```

### Q3: Crontab没有执行

**原因**：Cron服务未启动或配置有误

**解决**：
```bash
# 检查cron服务
sudo systemctl status cron

# 重启cron服务
sudo systemctl restart cron

# 检查crontab日志
sudo journalctl -u cron -f

# 验证crontab任务
sudo crontab -l
```

### Q4: 日志文件过大

**解决**：使用logrotate自动轮转
```bash
# 创建logrotate配置
sudo tee /etc/logrotate.d/campus-login > /dev/null << 'EOF'
/var/log/campus_login.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
}
EOF

# 测试logrotate
sudo logrotate -v /etc/logrotate.d/campus-login
```

### Q5: 密码包含特殊字符导致失败

**解决**：对特殊字符进行URL编码

```bash
# 使用 urlencode 函数
urlencode() {
    local string="$1"
    echo -n "$string" | jq -sRr @uri
}

# 在脚本中使用
encoded_password=$(urlencode "$PASSWORD")
```
