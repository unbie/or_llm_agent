# 第四章 路径优化模型及算法设计

## 4.1 模型描述

本文研究的问题为带时间窗约束的生鲜物流车辆路径问题（Vehicle Routing Problem with Time Windows and Freshness Constraints, VRPTW-FC）。该问题可描述如下：

某生鲜配送中心（仓库，记为节点 $0$）拥有 $m$ 辆同质配送车辆，每辆车的最大载重量为 $Q$。配送中心需向 $n$ 个客户配送生鲜产品，每个客户 $i$（$i = 1, 2, \ldots, n$）具有确定的需求量 $q_i$、地理坐标 $(x_i, y_i)$ 以及服务时间窗 $[e_i, l_i]$。车辆从配送中心出发，依次访问若干客户完成配送任务后返回配送中心，要求每个客户恰好被一辆车访问一次。

从图论角度，该问题可建模为定义在完全有向图 $G = (V, A)$ 上的组合优化问题，其中节点集 $V = \{0\} \cup \{1, 2, \ldots, n\}$ 包含仓库节点和全部客户节点，弧集 $A = \{(i, j) \ | \ i, j \in V, \ i \neq j\}$ 表示节点间的所有可达路径。每条弧 $(i, j)$ 关联一个非负的欧氏距离 $d_{ij}$ 和对应的行驶时间 $t_{ij}$。问题的目标是寻找 $K^*$（$K^* \leq m$）条从仓库出发并返回仓库的回路，使得每个客户恰好被一条回路访问，且所有约束得到满足的同时总配送成本最小化。

与传统 VRPTW 问题不同，生鲜物流场景下需要额外考虑以下特殊因素：

（1）**冷链制冷成本**：生鲜产品在运输过程中需要全程冷链保温，车辆行驶期间产生持续的制冷能耗成本。制冷系统的运行功率与行驶时间成正比，构成不可忽略的运营支出。

（2）**货物新鲜度衰减**：生鲜产品在运输和装卸过程中会发生品质损耗，其新鲜度随时间呈指数衰减规律。运输过程中的温度波动和装卸环节的暴露均会加速品质劣化。当衰减率超过允许阈值时，产生与货物价值成正比的货损成本。

（3）**软硬双层时间窗约束**：每个客户同时具有软时间窗 $[e_i, l_i]$ 和硬时间窗 $[E_i, L_i]$（$E_i \leq e_i$，$l_i \leq L_i$）。软时间窗反映客户的期望服务时段，硬时间窗为绝对不可违反的服务边界。车辆在软时间窗外但硬时间窗内到达时产生与偏离程度成正比的惩罚成本，超出硬时间窗则产生极高的违约惩罚。

综上，本文的优化目标是在满足车辆容量约束和时间窗约束的前提下，最小化包含车辆固定成本、运输距离成本、冷链制冷成本、货损成本和时间窗惩罚成本在内的综合配送总成本。该问题是经典 VRPTW 的扩展变体，属于 NP-hard 组合优化问题，其计算复杂性使得精确算法在大规模实例上难以实用，需要采用元启发式方法进行高效近似求解。

## 4.2 模型建立

### 4.2.1 参数符号说明

**（1）集合与索引**

| 符号                        | 含义                         |
| :-------------------------- | :--------------------------- |
| $V_0 = \{0\}$               | 配送中心（仓库）节点集合     |
| $V_c = \{1, 2, \ldots, n\}$ | 客户节点集合，$n$ 为客户总数 |
| $V = V_0 \cup V_c$          | 全部节点集合                 |
| $K = \{1, 2, \ldots, m\}$   | 车辆集合，$m$ 为可用车辆总数 |
| $i, j$                      | 节点索引，$i, j \in V$       |
| $k$                         | 车辆索引，$k \in K$          |

**（2）已知参数**

| 符号         | 含义                           | 取值/单位                                       |
| :----------- | :----------------------------- | :---------------------------------------------- |
| $Q$          | 车辆最大载重量                 | 200（单位量）                                   |
| $q_i$        | 客户 $i$ 的需求量              | 由算例给定                                      |
| $(x_i, y_i)$ | 节点 $i$ 的地理坐标            | 由算例给定                                      |
| $d_{ij}$     | 节点 $i$ 到节点 $j$ 的欧氏距离 | $d_{ij} = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$ |
| $v$          | 车辆行驶速度                   | 40 km/h                                         |
| $t_{ij}$     | 节点 $i$ 到节点 $j$ 的行驶时间 | $t_{ij} = d_{ij} / v$（h）                      |
| $s_i$        | 客户 $i$ 的服务时间            | 90 min（由算例给定）                            |
| $[e_i, l_i]$ | 客户 $i$ 的软时间窗            | 由算例给定（min）                               |
| $[E_i, L_i]$ | 客户 $i$ 的硬时间窗            | $E_i = \max(0, e_i)$，$L_i = \min(l_0, l_i)$    |

**（3）成本参数**

| 符号       | 含义                 | 取值       |
| :--------- | :------------------- | :--------- |
| $f$        | 车辆固定成本（每车） | 240 元/车  |
| $c$        | 单位距离运输成本     | 3 元/km    |
| $c_t$      | 单位时间制冷成本     | 15 元/h    |
| $p$        | 生鲜产品单价         | 5000 元/吨 |
| $\theta_1$ | 运输损耗系数         | 0.002      |
| $\theta_2$ | 装卸损耗系数         | 0.005      |
| $\delta_1$ | 允许损耗阈值         | 0.02       |
| $z_1$      | 早到惩罚系数         | 20 元/h    |
| $z_2$      | 迟到惩罚系数         | 40 元/h    |
| $M$        | 硬时间窗违反惩罚     | 300 元     |

**（4）决策变量**

| 符号      | 含义                                                              |
| :-------- | :---------------------------------------------------------------- |
| $x_{ijk}$ | 0-1 变量，车辆 $k$ 从节点 $i$ 直接行驶至节点 $j$ 时取 1，否则取 0 |
| $y_{ik}$  | 0-1 变量，客户 $i$ 由车辆 $k$ 服务时取 1，否则取 0                |
| $a_{ik}$  | 连续变量，车辆 $k$ 到达客户 $i$ 的时刻（min）                     |
| $w_{ik}$  | 连续变量，车辆 $k$ 在客户 $i$ 处的累计装卸服务时间（h）           |

### 4.2.2 目标函数

本模型的总配送成本由五个分项构成：

$$
\min \ C_{total} = C_{11} + C_{12} + C_{13} + C_2 + C_3 \tag{1}
$$

**（1）车辆固定成本 $C_{11}$**

车辆固定成本与投入使用的车辆数量成正比，包括车辆折旧、驾驶员工资等固定支出：

$$
C_{11} = f \cdot \sum_{k \in K} \max_{i \in V_c} y_{ik} = f \cdot K^{*} \tag{2}
$$

其中 $K^{*}$ 为实际使用的车辆数量（即非空路径的条数）。

**（2）运输距离成本 $C_{12}$**

运输距离成本与车辆行驶的总里程成正比，反映燃油消耗、轮胎磨损等可变运营成本：

$$
C_{12} = c \cdot \sum_{k \in K} \sum_{i \in V} \sum_{j \in V} d_{ij} \cdot x_{ijk} \tag{3}
$$

**（3）冷链制冷成本 $C_{13}$**

生鲜产品在运输全程需维持冷链环境，制冷成本与车辆行驶时间成正比：

$$
C_{13} = c_t \cdot \sum_{k \in K} T_k^{drive} \tag{4}
$$

其中 $T_k^{drive}$ 为车辆 $k$ 的总行驶时间（不含在客户处的服务时间）：

$$
T_k^{drive} = \sum_{i \in V} \sum_{j \in V} t_{ij} \cdot x_{ijk} \tag{5}
$$

**（4）货损成本 $C_2$（新鲜度衰减模型）**

生鲜产品在运输和装卸过程中发生品质衰减，采用指数衰减模型描述新鲜度变化。对于车辆 $k$ 路径上的客户 $i$，其新鲜度衰减率 $r_{ik}$ 定义为：

$$
r_{ik} = 1 - \exp\left(-\theta_1 \left(\frac{a_{ik}}{60} - w_{ik}\right) - \theta_2 \cdot w_{ik}\right) \tag{6}
$$

其中 $a_{ik}/60$ 为到达时刻（转换为小时），$w_{ik}$ 为累计装卸服务时间（小时）。$\theta_1$ 和 $\theta_2$ 分别反映运输过程和装卸过程对产品品质的影响程度。

当衰减率超过允许阈值 $\delta_1$ 时，产生与需求量成正比的货损成本：

$$
C_2 = p \cdot \sum_{k \in K} \sum_{i \in V_c} q_i \cdot \max(r_{ik} - \delta_1, \ 0) \cdot y_{ik} \tag{7}
$$

**（5）时间窗惩罚成本 $C_3$**

采用分段线性函数描述时间窗违反的惩罚成本。对于客户 $i$，车辆 $k$ 在时刻 $a_{ik}$ 到达时的惩罚函数为：

$$
\varphi_i(a_{ik}) =
\begin{cases}
z_1 \cdot \dfrac{e_i - a_{ik}}{e_i - E_i} & E_i \leq a_{ik} < e_i \quad \text{（软早到区间）} \\[10pt]
0 & e_i \leq a_{ik} \leq l_i \quad \text{（正常服务区间）} \\[10pt]
z_2 \cdot \dfrac{a_{ik} - l_i}{L_i - l_i} & l_i < a_{ik} \leq L_i \quad \text{（软迟到区间）} \\[10pt]
M & a_{ik} < E_i \ \text{或} \ a_{ik} > L_i \quad \text{（硬违反）}
\end{cases}
\tag{8}
$$

总时间窗惩罚成本为：

$$
C_3 = \sum_{k \in K} \sum_{i \in V_c} \varphi_i(a_{ik}) \cdot y_{ik} \tag{9}
$$

### 4.2.3 模型建立

综合以上目标函数与约束条件，生鲜物流 VRPTW-FC 问题的完整数学规划模型如下：

$$
\min \ C_{total} = C_{11} + C_{12} + C_{13} + C_2 + C_3 \tag{10}
$$

**约束条件：**

**（1）客户访问约束**：每个客户恰好被一辆车访问一次。

$$
\sum_{k \in K} y_{ik} = 1, \quad \forall \ i \in V_c \tag{11}
$$

**（2）车辆容量约束**：每辆车服务的客户总需求量不超过车辆最大载重量。

$$
\sum_{i \in V_c} q_i \cdot y_{ik} \leq Q, \quad \forall \ k \in K \tag{12}
$$

**（3）流量守恒约束**：每辆车从配送中心出发，访问若干客户后返回配送中心，且在每个中间节点进出平衡。

$$
\sum_{j \in V} x_{0jk} = \sum_{j \in V} x_{j0k} = \max_{i \in V_c} y_{ik}, \quad \forall \ k \in K \tag{13}
$$

$$
\sum_{i \in V} x_{ijk} = \sum_{i \in V} x_{jik} = y_{jk}, \quad \forall \ j \in V_c, \ k \in K \tag{14}
$$

**（4）时间连续性约束**：车辆在相邻节点间的到达时刻需满足行驶时间和服务时间的递推关系，并保证到达时刻不早于客户的最早服务时间。

$$
a_{jk} \geq a_{ik} + s_i + t_{ij} \cdot 60 - M'(1 - x_{ijk}), \quad \forall \ i \in V, \ j \in V_c, \ k \in K \tag{15}
$$

$$
a_{ik} \geq e_i \cdot y_{ik}, \quad \forall \ i \in V_c, \ k \in K \tag{16}
$$

其中 $M'$ 为一个充分大的常数。式（15）表示若车辆 $k$ 从节点 $i$ 直接行驶至节点 $j$，则到达 $j$ 的时刻不早于离开 $i$ 的时刻加上行驶时间；式（16）要求车辆到达时刻不早于客户的最早服务时间（若到达过早则等待至时间窗开启）。

**（5）子回路消除约束**：式（15）中的时间连续性约束隐含了子回路消除功能——由于到达时刻 $a_{ik}$ 为严格递增的连续变量，任何不经过仓库的子回路都会导致时间递推矛盾，因此该约束在保证时间递推的同时自然消除了非法子回路。

**（6）决策变量耦合约束**：路径决策变量 $x_{ijk}$ 与服务分配变量 $y_{ik}$ 之间需保持一致性：

$$
x_{ijk} \leq y_{ik}, \quad x_{ijk} \leq y_{jk}, \quad \forall \ i, j \in V, \ k \in K \tag{17}
$$

即车辆 $k$ 只有在服务了节点 $i$ 和节点 $j$ 的前提下，才能在两节点间建立行驶弧。

**（7）累计服务时间递推约束**：

$$
w_{jk} = w_{ik} + \frac{s_j}{60} \cdot x_{ijk}, \quad \forall \ i \in V, \ j \in V_c, \ k \in K \tag{18}
$$

**（8）变量约束**：

$$
x_{ijk} \in \{0, 1\}, \quad \forall \ i, j \in V, \ k \in K \tag{19}
$$

$$
y_{ik} \in \{0, 1\}, \quad \forall \ i \in V_c, \ k \in K \tag{20}
$$

$$
a_{ik} \geq 0, \quad w_{ik} \geq 0, \quad \forall \ i \in V, \ k \in K \tag{21}
$$

**模型分析**：上述模型为混合整数非线性规划（MINLP）模型。模型中包含 $O(n^2 m)$ 个 0-1 整数决策变量 $x_{ijk}$ 和 $O(nm)$ 个 0-1 变量 $y_{ik}$，以及 $O(nm)$ 个连续变量 $a_{ik}$ 和 $w_{ik}$。目标函数中的指数衰减项（式6）引入了非线性特征，分段线性惩罚函数（式8）虽可通过引入辅助变量线性化，但会进一步增加问题规模。

从计算复杂性理论的角度，即使不考虑新鲜度衰减和时间窗惩罚的非线性成分，其内核问题——带容量和时间窗约束的车辆路径问题（CVRPTW）——已被证明是强 NP-hard 问题。当客户规模 $n$ 较大时（如本文算例中 $n = 100$），0-1 决策变量数量达到 $100^2 \times 25 = 250{,}000$ 量级，精确求解方法（如分支定价法、分支切割法）的计算复杂度呈指数增长，难以在合理时间内获得全局最优解。

因此，本文采用自适应大邻域搜索（Adaptive Large Neighborhood Search, ALNS）元启发式算法进行近似求解。ALNS 算法不直接求解上述数学规划模型，而是在解空间中通过迭代式的破坏-修复操作搜索高质量可行解，其求解效率与解质量之间的平衡使其成为求解大规模 VRP 问题的主流方法。

# 第五章 基于ALNS算法的问题求解

## 5.1 算法设计

### 5.1.1 ALNS算法基本原理

自适应大邻域搜索算法（Adaptive Large Neighborhood Search, ALNS）由 Ropke 和 Pisinger 于2006年提出，是大邻域搜索算法（LNS）的扩展。其核心思想是维护多个破坏（Destroy）算子和修复（Repair）算子，在迭代过程中通过自适应权重机制动态选择算子组合，从而兼顾搜索的广度与深度。相比于固定邻域结构的局部搜索方法，ALNS 通过在不同粒度的邻域间切换，显著提升了逃离局部最优的能力。

**解的表示**：本文采用路径序列编码方式表示 VRP 的可行解。一个解 $s$ 由 $K^*$ 条路径组成，每条路径表示为从仓库出发并返回仓库的有序节点序列：

$$
s = \{R_1, R_2, \ldots, R_{K^*}\}, \quad R_k = (0, v_{k1}, v_{k2}, \ldots, v_{k,n_k}, 0)
$$

其中 $v_{k1}, v_{k2}, \ldots, v_{k,n_k}$ 为路径 $k$ 依次访问的客户节点。在程序实现中，解以嵌套列表形式存储，如 `[[0, 3, 5, 7, 0], [0, 2, 8, 0], ...]`。

**算法总体流程**如下：

（1）生成初始可行解 $s$，令当前解 $s_{cur} = s$，全局最优解 $s^* = s$；

（2）在每次迭代中，基于轮盘赌机制从破坏算子集 $\mathcal{D} = \{d_1, d_2, d_3\}$ 和修复算子集 $\mathcal{R} = \{r_1, r_2\}$ 中各选择一个算子；

（3）破坏算子从当前解中移除部分客户节点，修复算子将被移除的客户重新插入解中，生成新解 $s'$；

（4）对新解进行可行性验证（客户覆盖完整性、容量约束、时间窗约束），不可行解直接拒绝；

（5）根据模拟退火（Simulated Annealing, SA）接受准则决定是否接受可行新解；

（6）根据新解的质量更新所选算子的权重；

（7）重复步骤（2）—（6）直至满足终止条件（达到最大迭代次数 $N$）。

### 5.1.2 初始解构造

初始解的质量对ALNS算法的收敛效率有显著影响。本文采用多策略初始解构造方法，生成 3 个初始解并择优选取：

- **策略一（需求优先）**：将所有客户按需求量 $q_i$ 降序排列，优先为大需求客户分配路径，采用贪心插入法逐步构建可行路线；
- **策略二（时间窗紧迫度优先）**：将客户按时间窗宽度 $(l_i - e_i)$ 升序排列，优先为时间窗紧迫的客户安排配送；
- **策略三（随机构造）**：对客户进行随机排列后贪心插入，增加初始解的多样性。

三种策略各自生成一个可行解后，选择总成本最低的解作为 ALNS 搜索的起始解。

### 5.1.3 破坏算子设计

本文设计了 3 个破坏算子，从不同维度对当前解进行扰动。三种算子分别侧重于全局随机性、路径结构重组和局部精细调整，形成互补的搜索策略：

**（1）随机移除算子（Random Removal）**

从当前解中收集所有非仓库客户节点，随机采样 $k$ 个节点进行移除。具体步骤为：①遍历所有路径，提取全部客户节点及其位置索引 $(r_i, p_i, v_i)$；②根据当前破坏比例 $\text{ratio}$ 计算移除数量 $k = \lceil n_{\text{total}} \times \text{ratio} \rceil$；③无放回随机采样 $k$ 个节点；④按位置索引降序逐一移除，避免索引偏移错误；⑤清除移除后产生的空路径。该算子具有最强的随机性，能够有效维持搜索的多样性，避免算法过早收敛。其时间复杂度为 $O(n)$。

**（2）路径移除算子（Route Removal）**

随机选择一条非空路径，将该路径上的所有客户节点整体移除。具体步骤为：①筛选所有包含客户节点的非空路径；②随机选择一条路径；③提取该路径中的全部客户节点作为待重插入集合；④从解中删除该路径。该算子实施路径级别的大规模扰动，能够释放一辆车辆的全部客户资源，使修复算子有机会重新优化车辆分配方案，潜在地减少使用车辆数量。其时间复杂度为 $O(K^*)$，其中 $K^*$ 为当前路径数。

**（3）连续节点移除算子（String Removal）**

在随机选择的路径中，移除一段地理上连续的客户节点子序列。具体步骤为：①随机选择一条包含多个客户的路径；②在该路径中随机确定起始位置；③从起始位置连续移除 $k$ 个节点（$k$ 由破坏比例决定）。该算子保持了被移除节点的地理邻近性和服务时序关系，有利于对局部路径结构进行精细调整。其时间复杂度为 $O(n)$。

### 5.1.4 修复算子设计

本文设计了 2 个修复算子，将被移除的客户节点重新插入解中：

**（1）贪心插入算子（Greedy Insert）**

对每个待插入客户节点 $v$，遍历当前解中所有可行的插入位置，选择成本增量最小的位置执行插入。具体步骤为：

① 对每条路径 $R_k$，检查容量约束：当前路径载重 $\sum_{j \in R_k} q_j + q_v \leq Q$；

② 对满足容量约束的每个可行插入位置 $p$（$1 \leq p \leq |R_k| - 1$），计算插入前后路径的完整成本变化量：

$$
\Delta C(v, R_k, p) = C_{var}(R_k^{+v,p}) - C_{var}(R_k)
$$

其中 $C_{var}(\cdot)$ 为路径变动成本函数（包含 $C_{12} + C_{13} + C_2 + C_3$），$R_k^{+v,p}$ 表示在位置 $p$ 插入节点 $v$ 后的路径；

③ 同时评估新建路径的成本：$C_{new}(v) = C_{var}([0, v, 0]) + f$（含固定成本）；

④ 选择全局成本增量最小的方案执行插入。

需要特别指出的是，修复算子在评估插入位置时，调用完整的成本计算函数 `calculate_route_cost()` 进行精确评估，而非使用简化的距离三角不等式近似 $\Delta d = d_{i,v} + d_{v,j} - d_{i,j}$。后者仅考虑距离成本，完全忽略了新鲜度衰减（$C_2$）和时间窗惩罚（$C_3$）对插入决策的影响，可能导致将节点插入距离最近但时间窗严重违反的位置。采用完整成本评估确保了插入决策与目标函数的一致性。其时间复杂度为 $O(n^2 K^*)$。

**（2）后悔插入算子（Regret Insert）**

后悔插入算法引入"后悔值"（Regret Value）概念，通过全局视角优化插入顺序。对于待插入集合中的每个节点 $v$，定义其后悔值为：

$$
\text{Regret}(v) = \Delta C_2^{*}(v) - \Delta C_1^{*}(v)
$$

其中 $\Delta C_1^{*}(v)$ 和 $\Delta C_2^{*}(v)$ 分别为节点 $v$ 在所有可行位置中的最小和次小成本增量。后悔值越大，说明该节点对插入位置的敏感度越高——若不立即将其插入最佳位置，在后续其他节点占据该位置后，该节点只能退而选择次优位置，由此造成的额外成本即为后悔值。

具体步骤为：① 对每个待插入节点 $v$，计算其在所有可行位置的成本增量并排序；② 取最佳与次佳成本增量之差作为后悔值；③ 选择后悔值最大的节点，将其插入最佳位置；④ 从待插入集合中移除该节点，重复上述过程直至所有节点插入完毕。

该策略在时间窗约束紧凑的问题中表现优异：时间窗紧迫的客户通常可行插入位置少，后悔值高，从而被优先安排，避免了后期因位置被占用而产生高额惩罚。其时间复杂度为 $O(n^2 K^*)$。

### 5.1.5 模拟退火接受准则

本文采用模拟退火（SA）准则作为新解的接受机制。对于新解 $s'$，令 $\Delta = C(s') - C(s_{cur})$，接受概率为：

$$
P(\text{accept}) =
\begin{cases}
1 & \text{if } \Delta < 0 \\
\exp(-\Delta / T) & \text{if } \Delta \geq 0
\end{cases}
\tag{21}
$$

其中 $T$ 为当前温度参数。初始温度设为当前解成本的 10%：

$$
T_0 = \max(0.10 \times C(s_{cur}), \ 100) \tag{22}
$$

冷却系数 $\alpha$ 采用自适应设定，使温度在 $N$ 次迭代后衰减至初始温度的 2%：

$$
\alpha = 0.02^{1/N} \tag{23}
$$

每次迭代后温度更新为 $T \leftarrow T \times \alpha$。

为防止模拟退火在高温阶段接受质量极差的解，引入成本上限保护机制：

$$
C_{limit} = \max(1.5 \times C(s_{cur}), \ 2.0 \times C(s^*)) \tag{24}
$$

当新解成本 $C(s') > C_{limit}$ 时，直接拒绝该解，不进入概率接受判断。

### 5.1.6 自适应权重更新机制

ALNS算法的核心在于根据算子的历史表现自适应调整其选择概率。本文采用基于分数的四档奖励体系：

| 奖励等级 | 符号       | 分数 | 触发条件                   |
| :------- | :--------- | :--- | :------------------------- |
| 全局最优 | $\sigma_1$ | 33   | 新解为全局历史最优解       |
| 改进     | $\sigma_2$ | 9    | 新解优于当前解但非全局最优 |
| 接受     | $\sigma_3$ | 3    | 新解被SA准则接受但未改进   |
| 拒绝     | $\sigma_4$ | 0    | 新解被拒绝                 |

算子权重按以下公式更新：

$$
w_i^{(t+1)} = (1 - \rho) \cdot w_i^{(t)} + \rho \cdot \sigma \tag{25}
$$

其中 $\rho = 0.1$ 为记忆系数，控制历史权重与当次反馈的混合比例。

**权重下限保护**：为防止算子因连续低分而权重趋于零（算子饥饿现象），设置权重下限：

$$
w_i^{(t+1)} = \max\left(w_i^{(t+1)}, \ w_{min}\right), \quad w_{min} = 0.1 \tag{26}
$$

**周期性归一化**：每隔 $\lfloor 0.25N \rfloor$ 次迭代，对所有算子权重进行归一化处理：

$$
w_i \leftarrow \frac{w_i}{\sum_{j} w_j} \times |\mathcal{O}| \tag{27}
$$

其中 $|\mathcal{O}|$ 为算子总数，归一化使权重均值恢复为 1.0，避免权重整体漂移。

### 5.1.7 自适应破坏比例

破坏比例（即每次迭代移除的客户节点数占总客户数的比例）对算法性能有重要影响。比例过小导致搜索步幅不足，难以跳出局部最优；比例过大则破坏解的结构，修复算子难以恢复高质量解。

本文设计了基于无改善迭代计数器 $\eta$ 的三级自适应破坏比例机制：

$$
\text{ratio} =
\begin{cases}
[12\%, \ 18\%] & \text{if } \eta \leq 0.27N \quad \text{（正常优化阶段）} \\[6pt]
[15\%, \ 20\%] & \text{if } 0.27N < \eta \leq 0.53N \quad \text{（中期停滞阶段）} \\[6pt]
[20\%, \ 30\%] & \text{if } \eta > 0.53N \quad \text{（长期停滞阶段）}
\end{cases}
\tag{28}
$$

在每个阶段内，实际移除数量在区间内随机取值，兼顾确定性与随机性。

### 5.1.8 重启与再加热机制

当无改善迭代计数器 $\eta$ 超过重启阈值 $\eta_{max} = \max(60, \lfloor 0.6N \rfloor)$ 时，执行重启操作：

（1）将当前解回退至全局最优解 $s^*$；

（2）执行再加热，将温度恢复至初始温度的 50%：$T \leftarrow 0.5 \times T_0$；

（3）重置无改善计数器 $\eta = 0$。

重启机制使算法在全局最优解附近重新进行高温探索，有助于发现被忽略的搜索区域。

### 5.1.9 后处理优化

ALNS主循环结束后，对全局最优解 $s^*$ 的每条路径执行 2-opt 局部搜索优化。2-opt算子通过反转路径中的一个子序列来消除交叉路径，仅在优化后成本降低时才保留改进。

### 5.1.10 算法流程

综合上述各组件，完整的 ALNS 算法流程如算法1所示。

```
算法1: ALNS算法求解生鲜物流VRPTW-FC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
输入: 问题数据 D, 最大迭代次数 N
输出: 最优解 s*, 最优成本 C*

 1:  for i = 1 to 3 do                           // 多策略初始解
 2:      s_i ← ConstructInitialSolution(D, 策略i)
 3:  s ← argmin_{s_i} C(s_i)                     // 择优
 4:  s* ← s; C* ← C(s)
 5:  T ← max(0.10 × C*, 100)                     // SA初始温度
 6:  α ← 0.02^(1/N)                              // 冷却系数
 7:  w_d ← [1.0, 1.0, 1.0]                       // 破坏算子权重
 8:  w_r ← [1.0, 1.0]                            // 修复算子权重
 9:  η ← 0                                       // 无改善计数器
10:
11:  for iter = 1 to N do
12:      d ← RouletteSelect(Destroy, w_d)         // 轮盘赌选择
13:      r ← RouletteSelect(Repair, w_r)
14:      ratio ← AdaptiveRatio(η)                 // 自适应破坏比例
15:      (s_partial, R) ← d(s, ratio)             // 破坏
16:      s' ← r(s_partial, R)                     // 修复
17:
18:      if Validate(s') then
19:          Δ ← C(s') − C(s)
20:          if Δ < 0 then
21:              s ← s'
22:              if C(s') < C* then
23:                  s* ← s'; C* ← C(s')
24:                  UpdateWeights(σ₁ = 33)        // 全局最优
25:              else
26:                  UpdateWeights(σ₂ = 9)         // 改进
27:              η ← 0
28:          elif C(s') ≤ C_limit and rand() < exp(−Δ/T) then
29:              s ← s'
30:              UpdateWeights(σ₃ = 3)             // SA接受
31:              η ← η + 1
32:          else
33:              UpdateWeights(σ₄ = 0)             // 拒绝
34:              η ← η + 1
35:
36:      T ← T × α                                // 温度冷却
37:
38:      if η > η_max then                         // 重启判定
39:          s ← s*; T ← 0.5 × T₀
40:          η ← 0
41:
42:      if (iter mod ⌊0.25N⌋) = 0 then           // 权重归一化
43:          NormalizeWeights(w_d, w_r)
44:
45:  s* ← LocalSearch_2opt(s*)                     // 后处理
46:  return s*, C*
```

### 5.3.3 收敛性分析

从算法的收敛曲线可以观察到四个典型阶段：

（1）**快速下降期**（第 1 — 200 轮迭代）：初始解在ALNS搜索下快速改进，总成本大幅下降。此阶段温度较高，SA准则以较大概率接受劣解，搜索具有较强的探索能力。

（2）**波动探索期**（第 200 — 600 轮迭代）：SA温度处于中等水平，当前解成本呈现显著波动，体现了算法在探索（Exploration）与利用（Exploitation）之间的平衡。全局最优成本在此阶段仍保持稳步下降趋势。

（3）**精细优化期**（第 600 — 900 轮迭代）：随着温度降低，SA接受劣解的概率显著下降，搜索逐步转向利用模式。算法在全局最优解附近进行精细搜索，间歇性发现更优解。

（4）**收敛稳定期**（第 900 — 1000 轮迭代）：算法基本收敛，成本趋于稳定。最后一次改进出现在约第 900 轮迭代，验证了将迭代次数从 800 提升至 1000 的必要性。
