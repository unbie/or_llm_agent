## 🔧 脚本对比速查表

### campus_network_login.sh (基础脚本)
```
适合人群：要求简单、追求轻量的用户
文件大小：~3KB
配置方式：编辑脚本文件
参数位置：第15-24行
推荐场景：简单部署，个人使用

使用方法：
  1. nano campus_network_login.sh
  2. 修改 USERNAME, PASSWORD 等参数
  3. bash campus_network_login.sh
  4. crontab -e (加入定时任务)

特点：
  ✓ 最小化，易于理解
  ✓ 无外部依赖（除curl）
  ✓ 运行快速
  ✗ 无配置文件
  ✗ 功能有限
```

### campus_network_login_advanced.sh (高级脚本)
```
适合人群：需要高级功能的用户
文件大小：~10KB
配置方式：配置文件 /etc/campus_login.conf
功能特性：监控、告警、多模式

使用方法：
  1. ./campus_network_login_advanced.sh --generate-config
  2. nano /etc/campus_login.conf (编辑配置)
  3. ./campus_network_login_advanced.sh --login (测试)
  4. ./campus_network_login_advanced.sh --monitor (监控)
  5. crontab -e (加入定时任务)

支持的命令：
  --login      : 执行登录
  --check      : 检查网络
  --monitor    : 实时监控
  --status     : 显示状态
  --help       : 显示帮助
  
特点：
  ✓ 功能完整
  ✓ 配置灵活
  ✓ 实时监控
  ✓ 邮件告警
  ✗ 脚本稍大
```

```
适合人群：新手用户（推荐）

  (按照提示输入参数，脚本自动完成所有配置)

自动完成的任务：

特点：
  ✓ 一键部署

  ✗ 需要root权限
```
