# 学术论文Word模板使用说明

## 方案一：使用Pandoc + 自定义模板（推荐）

### 第一步：安装Pandoc
1. 访问 https://pandoc.org/installing.html
2. 下载Windows版本安装程序
3. 安装完成后，在命令行输入 `pandoc --version` 验证

### 第二步：创建学术模板（可选）
如果需要自定义格式，可以先生成一个参考模板：
```bash
pandoc --print-default-data-file reference.docx > academic_template.docx
```

然后在Word中打开 `academic_template.docx`，设置：
- **正文**: 宋体，小四号（12pt），行距1.5倍
- **标题1**: 黑体，三号（16pt），加粗，段前0.5行，段后0.5行
- **标题2**: 黑体，小三号（15pt），加粗，段前0.5行，段后0.5行
- **标题3**: 黑体，四号（14pt），加粗，段前0.5行，段后0.5行
- **标题4**: 黑体，小四号（12pt），加粗
- **页边距**: 上下2.54cm，左右3.17cm
- **页眉页脚**: 小五号（9pt），居中

### 第三步：运行批处理脚本
双击 `convert_to_word.bat` 即可自动转换

### 第四步：手动调整（如需要）
在Word中打开生成的文档，调整：
1. 封面页格式
2. 目录样式
3. 图片和表格位置
4. 页眉页脚内容

## 常见问题

### Q1: 数学公式无法显示？
**A**: Pandoc默认使用Word的内置公式编辑器。如果公式复杂，建议：
```bash
pandoc input.md -o output.docx --mathml
```

### Q2: 代码块格式丢失？
**A**: 使用 `--highlight-style` 参数，可选样式：
- tango（推荐，学术风格）
- pygments（代码高亮）
- monochrome（单色，适合打印）

### Q3: 表格边框不显示？
**A**: 在Word中手动设置表格边框，或在模板中预设表格样式。

### Q4: 目录无法更新？
**A**: 在Word中右键目录 → "更新域" → "更新整个目录"

## 学术论文格式检查清单

转换完成后，请检查以下项目：

- [ ] 标题层级正确（最多4级）
- [ ] 目录自动生成且可更新
- [ ] 章节编号正确（1, 1.1, 1.1.1格式）
- [ ] 正文字体统一（中文宋体，英文Times New Roman）
- [ ] 行距一致（1.5倍或1.25倍）
- [ ] 页边距符合要求
- [ ] 图片居中且有图注
- [ ] 表格有表头且有表注
- [ ] 代码块使用等宽字体
- [ ] 数学公式显示正确
- [ ] 参考文献格式统一
- [ ] 页眉页脚格式正确
