# 第五章 实验结果与对比分析

## 5.1 实验环境与参数设置

本研究的实验环境基于 Python 3.10 开发，核心算法在配置有高性能 CPU 的工作站上运行。为确保实验结果的公平性与复现性，LLM-ALNS 算法与基线 ALNS 算法采用统一的参数配置。

### 5.1.1 算法参数配置

算法参数设置如下：

- **迭代次数**：标准对比实验设置为 500 次迭代。
- **LLM 配置**：采用 DeepSeek-V3 模型，通过 API 调用进行 5 轮进化优化。
- **ALNS 设置**：采用模拟退火接收准则，单车固定成本 {11}$ 设定为 240。

### 5.3.1 核心演化逻辑：以增量投入换取系统鲁棒性

通过对比分析可以看出，LLM-ALNS 展现了一种超越人类直觉的优化路径：

1. **策略性运能扩张**：算法主动将车辆数从 34 辆增加至 35 辆，导致固定成本 {11}$ 上升。这一决策为系统提供了更高的调度灵活性。
2. **惩罚项的 爆发式削减**：由于增加了运能支持，算法能够更精准地匹配客户的时间窗要求，使得时间窗惩罚 $ 发生了显著下降（从 7502 降至 436），降幅高达 94.2%。
3. **非线性权衡平衡**：尽管为了实现更优的路径编排，算法在局部容忍了更高的新鲜度损耗 $。但在全局视角下，通过牺牲小额的固定资产投入和部分服务时效，成功对冲了极其昂贵的时间窗违约风险。

## 5.4 本章小结

1. **地理分布自适应**：LLM-ALNS 在处理具有明显空间聚集特征（c105）的配送任务时效果最佳。
2. **全局最优思维**：实验数据证明，LLM 进化的算子具备全局博弈能力，能够识别并实施局部成本上升、全局成本下降的复杂权衡策略。
