## 图表文本分析

### 柱状图分析

- 在 c1/c105 与 c2/c201 上，LLM 成本柱低于 ALNS、GA、ACO，体现出正向优势
- 在 c1/c101 与 c2/c205 上，ALNS 柱略低于 LLM，说明这两例仍是 ALNS 更强
- GA 在四个实例上都明显高于 LLM 与 ALNS
- ACO 在 c2/c205 上显著偏高，属于当前参数下的弱项

### 折线图分析

- LLM 与 ALNS 两条线整体贴近，差距在百分点以内
- GA 折线整体位于 LLM 与 ALNS 上方，性能弱于前两者
- ACO 折线在 c2/c205 出现明显抬升，拉大了与其余算法的差距

### LLM优势图分析

- 相对 GA 和 ACO，LLM 在四个实例的柱子均为正值
- 相对 ALNS，LLM 在 c1/c105、c2/c201 为正，在 c1/c101、c2/c205 为负
- 这说明 LLM 的主要优势当前体现在替代 GA 和 ACO 时更稳定，超越 ALNS 时呈实例相关
