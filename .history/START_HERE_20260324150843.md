## 🚀 3种部署方式

### 方式1：一键自动部署（推荐 ⭐⭐⭐）

```bash
sudo chmod +x install_campus_login.sh
sudo ./install_campus_login.sh
```

**优点**：自动完成所有配置  
**时间**：2-3分钟  
**适合**：所有用户  

---

### 方式2：使用高级脚本（灵活 ⭐⭐⭐⭐）

```bash
./campus_network_login_advanced.sh --generate-config
nano /etc/campus_login.conf
./campus_network_login_advanced.sh --login
```

**优点**：功能完整，配置灵活  
**时间**：5分钟  
**适合**：需要高级功能的用户  

---

### 方式3：使用基础脚本（最简单 ⭐⭐⭐）

```bash
nano campus_network_login.sh  # 修改参数
bash campus_network_login.sh
```

**优点**：脚本最小，最易理解  
**时间**：3分钟  
**适合**：只需基础功能的用户

## ❓ 常见问题

### Q: 我不知道选哪个脚本

**A**: 推荐使用部署脚本 `install_campus_login.sh`，它会自动完成所有配置。

查看：[SCRIPTS_COMPARISON.md](SCRIPTS_COMPARISON.md)

---

### Q: 我需要什么认证参数？

**A**: 学号、密码和认证ID，从校园网登录页面F12获取。

详见：[QUICK_START.md](QUICK_START.md) 的"获取认证参数"部分

---

### Q: 脚本如何自启动？

**A**: 部署脚本会自动配置。或者手动加入crontab：

```bash
*/5 * * * * /usr/local/bin/campus_network_login.sh
```

详见：[CAMPUS_LOGIN_GUIDE.md](CAMPUS_LOGIN_GUIDE.md) 的"开机自启配置"

---

### Q: 如何查看日志？

**A**: 
```bash
tail -f /var/log/campus_login.log
```

---

### Q: 脚本可以关闭吗？

**A**: 是的，编辑crontab删除对应行，或使用以下命令：

```bash
sudo systemctl disable campus-login.timer
```
