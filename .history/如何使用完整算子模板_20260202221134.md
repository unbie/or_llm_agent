# 如何让LLM生成完整的ALNS算子代码

## 问题诊断

你遇到的问题是：**LLM生成的代码缺少关键改进**，导致：
- 破坏算子（worst, related, shaw等）成功率低或为0%
- 修复算子可能生成不可行解（超容量）

## 根本原因

**heuristic_prompts.py** 文件已经包含完整正确的实现，但notebook在"LLM Output"阶段会让LLM重新生成代码，可能生成不完整的版本。

## 解决方案

### 方案1：直接使用模板文件（推荐）

在notebook中，让LLM **直接使用** heuristic_prompts.py 的内容，而不是重新生成：

```python
# 在notebook中执行
import sys
sys.path.append(r'd:\pythonProject\or_llm_agent')

# 直接从文件加载完整模板
from heuristic_prompts import HEURISTIC_PLUGIN_TEMPLATE

# 提取plugin代码
plugin_code = generator.extract_plugin_code(HEURISTIC_PLUGIN_TEMPLATE)

# 执行并创建插件实例
exec(plugin_code, globals())
plugin = HeuristicPlugin(**data)
```

### 方案2：引导LLM生成完整代码

如果必须让LLM生成，在prompt中强调：

```

   - history_removal: 完整的历史记录算法

2. **所有修复算子必须包含容量约束检查**：
   ```python
   # 在插入前必须检查

3. **容量从self.data获取**：
   ```python

   ```

```

## 关键改进点总结

### 破坏算子

1. **worst_removal** (第277-341行)
   ```python
   # 考虑需求因子
   dist_contrib = (self.dist_matrix[prev_node][node] + 
                  self.dist_matrix[node][next_node] - 
                  self.dist_matrix[prev_node][next_node])
   demand = customer.get('demand', 0)
   contrib = dist_contrib + demand * 0.01  # ← 关键改进
   ```

2. **shaw_removal** (第417-489行)
   ```python
   # 安全归一化（避免除零）
   max_distance = max(distances) if distances else 1.0
   if max_distance < 0.001:
       max_distance = 1.0  # ← 关键改进
   ```

```python

                  for n in route if n != 0)
